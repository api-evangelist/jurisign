# JuriSign API

eIDAS-compliant electronic signature REST API built and hosted in France. Provides document upload, sign requests, templates, bulk campaigns, public self-signing forms, webhooks, and audit proof downloads, with a free sandbox. Signature level is Simple Electronic Signature (SES) under eIDAS Regulation (EU) 910/2014.
